# Vyntrix Client

High-performance Minecraft launcher built with Rust (Tauri) and React/Tailwind.

## Features
- **Low RAM Usage:** Optimized Rust backend.
- **High FPS:** Minimal UI overhead.
- **Integrated Mod Management:** Direct Modrinth API integration.
- **Secure Auth:** Microsoft OAuth2 flow.

## Development
1. Install Node.js, Rust, and Wix Toolset.
2. `npm install`
3. `npm run tauri dev`

## Build
To generate the `installer.exe`:
`npm run tauri build`
